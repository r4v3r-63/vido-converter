# Included components

The Windows application includes Python (PSF License), the PyInstaller bootloader
(GPL with the PyInstaller distribution exception), and FFmpeg with its enabled
codecs. The official Chocolatey ffmpeg 7.1.1 package is installed with checksum
verification enabled. License files from that package accompany the application.

- Python license: https://docs.python.org/3/license.html
- PyInstaller license and exception: https://pyinstaller.org/en/stable/license.html
- FFmpeg licensing: https://ffmpeg.org/legal.html
- Windows FFmpeg build provider, build information and source links: https://www.gyan.dev/ffmpeg/builds/
- FFmpeg 7.1.1 source: https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz

FFmpeg is a separate executable invoked as a subprocess. Its bundled license
terms apply to that component. No third-party ownership is claimed.
