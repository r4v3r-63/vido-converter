КАДР — конвертер видео для Windows 10/11, 64 бит

1. Распакуйте весь ZIP в любую папку.
2. Запустите Kadr.exe двойным щелчком.
3. Откроется интерфейс в вашем браузере.
4. Добавьте видео, задайте параметры, нажмите «Конвертировать видео».
5. Скачайте результаты.

Ничего устанавливать не нужно: Python и FFmpeg уже внутри программы.
Доступ в интернет для конвертации не требуется.
Окно программы должно оставаться открытым во время работы.
Чтобы завершить работу, закройте окно программы (закрытие вкладки браузера
не останавливает программу).

Программа не имеет платной цифровой подписи издателя.
Лимит одной загрузки — 512 МБ и 100 файлов.
Исходные видео на вашем компьютере не изменяются.
