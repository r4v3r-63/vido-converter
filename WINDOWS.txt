КАДР — конвертер видео для Windows 10/11, 64 бит

1. Распакуйте весь ZIP в любую папку.
2. Запустите Kadr.exe двойным щелчком: откроется окно программы.
3. Нажмите «Добавить видео» и выберите файлы.
4. Укажите разрешение, FPS, формат и при необходимости удаление звука.
5. Выберите папку результатов и нажмите «Конвертировать видео».

Готовые видео сохраняются сразу в выбранную папку.
Браузер, скачивание результатов и подключение к интернету не нужны.
Python и FFmpeg встроены, ничего устанавливать не нужно.
Программных ограничений на количество и размер видео нет.
Исходники и существующие результаты не перезаписываются.
Обработку можно остановить кнопкой «Остановить».
Подробности ошибок — двойным щелчком по строке файла.
Программа не имеет платной цифровой подписи издателя.

В поле «Кодирование» можно выбрать CPU или доступную видеокарту.
Дождитесь завершения проверки видеокарт после запуска.
Для NVIDIA используется NVENC; для AMD — AMF; для Intel — Quick Sync.
Кодирование на GPU доступно для MP4/MKV; WebM обрабатывается на CPU.
Для проверки нагрузки GPU смотрите «Video Encode» в диспетчере задач.
