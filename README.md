# Кадр — пакетный конвертер видео

[![Checks](https://github.com/r4v3r-63/vido-converter/actions/workflows/checks.yml/badge.svg)](https://github.com/r4v3r-63/vido-converter/actions/workflows/checks.yml)

Локальное приложение с русским интерфейсом. Загрузите несколько видео, выберите разрешение, FPS, MP4/MKV/WebM и при необходимости удалите звук. Готовые файлы доступны отдельно и ZIP-архивом. Исходники не изменяются. Пропорции сохраняются с добавлением полей под выбранный размер.

## Запуск

### Готовая программа для Windows — без установки зависимостей

В [Releases](https://github.com/r4v3r-63/vido-converter/releases/latest) скачайте
`Kadr-Windows-x64.zip`, распакуйте и запустите `Kadr.exe`.
Python и FFmpeg включены. Интерфейс открывается автоматически в браузере.
Для конвертации интернет не нужен. Поддерживаются Windows 10/11 x64.
Не закрывайте окно программы до завершения обработки.

Сборка Windows выполняется в GitHub Actions при отправке тега `v*`:
тестируются исходники и готовый EXE, затем ZIP прикрепляется к релизу.

### Запуск из исходников (для разработки)

Нужны Python 3.10+ и FFmpeg с кодеками libx264, libvpx-vp9, AAC и libopus, доступный в PATH. Дополнительных Python-пакетов нет.

### Установка инструментов

- **Windows:** установите Python 3.10+ с [python.org](https://www.python.org/downloads/) с опцией добавления в PATH. Установите FFmpeg командой `winget install --id Gyan.FFmpeg -e`, затем откройте новый терминал.
- **macOS:** `brew install python ffmpeg` (нужен Homebrew).
- **Ubuntu / Debian:** `sudo apt-get update && sudo apt-get install -y python3 ffmpeg`.

Проверьте команды `python3 --version` (на Windows — `py -3 --version`), `ffmpeg -version` и `ffprobe -version`.

### Скачать и запустить

```sh
git clone https://github.com/r4v3r-63/vido-converter.git
cd vido-converter
python3 app.py
```

На Windows вместо последней команды используйте `py -3 app.py` или откройте `start.bat`. На Linux/macOS можно выполнить `sh start.sh`. Если проект уже скачан, используйте существующий каталог. В облачной среде каталог проекта — `/workspace/vido-converter`.

На своём компьютере откройте `http://127.0.0.1:8000`. Другой порт: `python3 app.py --port 8080`. Остановка: Ctrl+C. Сервер слушает только локальный интерфейс; приложение предназначено для личного использования, не для публикации в интернете.

### Как пользоваться

1. Выберите или перетащите видеофайлы.
2. Задайте общее разрешение, частоту кадров и формат для всего пакета.
3. Включите «Удалить звук», если нужны видео без аудио.
4. Нажмите «Конвертировать видео», дождитесь завершения и скачайте файлы или ZIP.

Обработка идёт на компьютере, где запущен Python-сервер. Если программа запущена в облачной среде, видео обрабатываются в этой среде.

Пакет: до 100 файлов, суммарно до 512 МБ. Обработка последовательная, один пакет за раз. Загрузка разбирается в оперативной памяти; для больших файлов потребуется отдельная реализация потоковой загрузки. Исходные файлы на сервере удаляются после обработки, результаты хранятся во временных каталогах `video-converter-*` до ручного удаления. Скачайте результаты перед очисткой временной папки.

При сохранении оригинального разрешения нечётные размеры округляются вниз до чётных для совместимости с кодеком. Используются первая видеодорожка и первая аудиодорожка; субтитры и дополнительные дорожки не переносятся. Повреждённые и неподдерживаемые видео показываются как ошибки, обработка остальных продолжается.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

GitHub Actions запускает проверки после push и для pull request на Python 3.10, 3.12 и 3.13. Подробности разработки — в [CONTRIBUTING.md](CONTRIBUTING.md).
