# Кадр — пакетный конвертер видео

Программа с собственным окном для Windows 10/11 x64. Браузер не нужен.

## Скачать и использовать

В [Releases](https://github.com/r4v3r-63/vido-converter/releases/latest)
скачайте `Kadr-Windows-x64.zip`, распакуйте и запустите `Kadr.exe`.
Ничего устанавливать не нужно: Python, Tk и FFmpeg встроены.

1. Нажмите «Добавить видео» и выберите нужные файлы.
2. Выберите разрешение, FPS, MP4/MKV/WebM и при необходимости «Удалить звук».
3. Укажите папку результатов и нажмите «Конвертировать видео».
4. Результаты сохраняются в папку автоматически. Кнопка «Открыть папку результатов» открывает её в проводнике.

Программных ограничений на количество файлов и их размер нет. Программа читает
исходные файлы напрямую, без загрузки на сервер и копирования во временное хранилище.
Достаточно места для готовых видео и одного обрабатываемого временного файла.
Обработка последовательная. Исходники и существующие файлы не перезаписываются:
результаты получают суффикс `_converted`, при совпадении имён — номер.
Кнопка «Остановить» прекращает обработку; завершённые результаты остаются.
Ошибки не останавливают остальные файлы, подробности доступны двойным щелчком по строке.

Пропорции сохраняются, при необходимости добавляются поля. Нечётные размеры
оригинала округляются вниз до чётных. Используются первая видеодорожка и первая
аудиодорожка; субтитры и дополнительные дорожки не переносятся.

## Разработка

Python 3.10+, Tkinter и FFmpeg/ffprobe в PATH. Запуск: `python desktop.py`.
На Windows используйте `start.bat`, на Linux/macOS — `sh start.sh`.
На Debian/Ubuntu: `sudo apt-get install python3 python3-tk ffmpeg`.

Проверки: `python -m unittest discover -s tests -v`.
Инструкции по разработке и сборке — в [CONTRIBUTING.md](CONTRIBUTING.md).

GitHub Actions собирает `--windowed` EXE по тегам `v*`, проверяет настоящее окно
и конвертацию встроенным FFmpeg, затем публикует архив и SHA256 в Releases.

## Выбор видеокарты

В поле «Кодирование» выберите CPU или доступную видеокарту. Программа проверяет
аппаратные кодировщики реальной пробной конвертацией. NVIDIA отображается с именем
карты и использует NVENC с явным индексом устройства; AMD — AMF, Intel — Quick Sync
(для AMD/Intel используется адаптер по умолчанию соответствующего API).
Аппаратное кодирование поддерживается для MP4/MKV (H.264). Для WebM выберите CPU.
Декодирование, масштабирование и изменение FPS выполняются на CPU. При ошибке
видеокарты программа показывает её в очереди и не переключается молча на CPU.
Наличие кодировщика зависит от GPU и установленного драйвера.
В диспетчере задач смотрите график «Video Encode», а не только «3D».

## Структура проекта

- `desktop.py` — окно программы, очередь и пользовательские действия.
- `engine.py` — команды FFmpeg, проверка GPU и пакетная обработка.
- `tests/` — проверки конвертации, сохранности файлов и готового EXE.
- `.github/workflows/` — проверки кода и сборка Windows.
- `WINDOWS.txt` — краткая инструкция, включённая в ZIP.
- `THIRD_PARTY.md` — сведения о встроенных компонентах.

Браузерный интерфейс удалён. История предыдущих версий остаётся в Git.
