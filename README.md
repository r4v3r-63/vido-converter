# Кадр — пакетный конвертер видео

Кадр — программа для Windows 10/11 x64 с отдельным окном для пакетной конвертации видео. Работает локально, без браузера и подключения к интернету. Не требует установки дополнительных компонентов.

Основные возможности:

- Обработка нескольких видео разных входных форматов.
- Сохранение в MP4, MKV и WebM.
- Выбор разрешения и частоты кадров с сохранением пропорций.
- Удаление звука из готовых видео.
- Кодирование на процессоре или совместимой видеокарте NVIDIA, AMD и Intel.
- Сохранение результатов в выбранную папку без изменения исходников.
- Очередь файлов, отображение состояния и остановка обработки.
- Светлая и тёмная темы с сохранением выбора.

Программных ограничений на количество и размер файлов нет. Для обработки необходимо свободное место на диске. Доступность аппаратного кодирования зависит от видеокарты и драйвера; оно поддерживается для MP4 и MKV.

Готовая программа доступна в [Releases](https://github.com/r4v3r-63/vido-converter/releases/latest).
