# Разработка

Нужны Python 3.10+, Tkinter, FFmpeg и ffprobe. Работайте в существующем каталоге.

Запуск: `python desktop.py`. Проверки: `python -m unittest discover -s tests -v`.
Тесты проверяют конвертацию, исходники, существующие результаты, выбор кодировщика,
а также совместимость старого HTTP API. Для HTTP-теста нужны локальные сокеты.

Windows workflow собирает GUI EXE со встроенными Tcl/Tk и FFmpeg. Готовый EXE
проходит `tests/smoke_packaged.py`: создаётся настоящее окно, добавляется файл,
запускается обработка и проверяется сохранение результата прямо в папку.
GPU необходимо дополнительно проверять на компьютерах с соответствующим
оборудованием и драйверами. В облачном runner тестируется CPU, наличие GPU там
не гарантировано. Пользовательский интерфейс показывает только кодировщики,
которые успешно выполнили пробное кодирование на текущем компьютере.
