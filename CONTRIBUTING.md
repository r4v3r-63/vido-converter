# Разработка

Нужны Python 3.10+ и FFmpeg (включая ffprobe). Python-зависимостей нет. Работайте в существующем каталоге репозитория.

1. Установите инструменты по README.
2. Запустите `python3 -m unittest discover -s tests -v` из корня проекта.
3. Запустите `python3 app.py`, откройте локальный адрес из вывода и проверьте интерфейс.

Тесты создают короткие видео с аудио, проверяют все выходные форматы, размеры, FPS и удаление звука. HTTP-тест проверяет пакет с повреждённым файлом, скачивание видео, ZIP и запрет скачивания исходников. Для HTTP-теста нужен доступ к локальным сокетам.

Перед отправкой изменений повторите тесты. GitHub Actions выполняет их на Linux с Python 3.10, 3.12 и 3.13. Изменения интерфейса дополнительно проверяйте в браузере: загрузка через выбор файлов и перетаскивание, сообщения ошибок, повторная конвертация.

Сервис предназначен для локального использования. Не меняйте адрес прослушивания на публичный без отдельной реализации авторизации, потоковой загрузки, ограничения ресурсов и очистки результатов.
